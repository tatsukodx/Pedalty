# 3Dモデル: UnityRoadMaster

## 概要
Unityで使える日本風ローポリ道路素材です。『Highway』『Crossing』『Road』があります。
またAssetStoreで配布している有料Assetの『EasyRoads3D』でも使用できます（後述）。

サンプルのゲームを作成しましたのでそちらで試すことも可能です。
https://play.unity.com/en/games/1ff45923-1798-4fab-abf5-abbe1f2426c8/unityroadmasterdemowebgl

## ファイルコンテンツ
（例：Basic_HighWay_1x2-C_Junction_Ver1_1）
- `Animation`:破壊モーションのアニメーションクリップファイル。
- `Mesh`: メインの3Dモデルの元データ(FBX)。
- `Mesh/Collider_Mesh`: Unity内のColliderで使用しているメッシュ。
- `Mesh/Fragment_Mesh`:破壊アニメーションで使用している破砕した後のメッシュ。
- `Prefab`: 完成モデル。
- `Prefab/Destroy`:破壊用アニメーションを適用しているモデル。
- `Textures`: メインの3Dモデルで使用しているテクスチャ。

＊使用しているマテリアルは『HighWay_Material』『Crossing_Material』『Road_Material』にそれぞれ入っています。また『Road_Unity_Ver1_1』『Basic_HighWay_1x2_Unity_Ver1_1
』『Basic_HighWay_1x2-C_Unity_Ver1_1』『Basic_HighWay_2x2_Unity_Ver1_1』にはEasyRoads3Dで使用するためのマテリアルとメッシュが入っております。


## 使用方法
1. Unity起動後に`UnityRoadMaster_Ver1_1`UnityAssetファイルをクリックしてください。
2. マテリアルは設定済みですがプロジェクトに合わせて調整してください。
3. EasyRoads3Dでの利用方法は別途説明している下記動画をご覧ください。
"UnityRoadMaster How to Set UP（https://youtu.be/RzKdKWGhGSE）"
"UnityRoadMaster Extra Data(https://youtu.be/139oGj9Y370)


## システム環境
- Unity2021.3.18f
- EasyRoad3d v3.2.4f2
