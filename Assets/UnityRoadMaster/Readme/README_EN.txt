# 3D Model: UnityRoadMaster


## Overview
This is a Japanese-style low-poly road asset pack that can be used in Unity. It includes "Highway" "Intersection" and "Road" models. Additionally, it can be used with the paid asset "EasyRoads3D," which is available on the Asset Store (details below).

A sample game has been created, and you can try it out here:
https://play.unity.com/en/games/1ff45923-1798-4fab-abf5-abbe1f2426c8/unityroadmasterdemowebgl

## File Contents
(Example: Basic_HighWay_1x2-C_Junction_Ver1_1)

- Animation: Animation clip file for destruction motion.
- Mesh: Source data for the main 3D model.
- Mesh/Collider_Mesh: Mesh used for Colliders in Unity.
- Mesh/Fragment_Mesh: Mesh used in destruction animations after fragmentation.
- Prefab: Completed model.
- Prefab/Destroy: Model with applied destruction animations.
- Textures: Textures used for the main 3D model.

The materials used are contained in 'HighWay_Material,' 'Crossing_Material,' and 'Road_Material.' Additionally, the materials and meshes used for EasyRoads3D are included in 'Road_Unity_Ver1_1,' 'Basic_HighWay_1x2_Unity_Ver1_1,' 'Basic_HighWay_1x2-C_Unity_Ver1_1,' and 'Basic_HighWay_2x2_Unity_Ver1_1.'


## Usage Instructions
1. After launching Unity, click on the UnityRoadMaster_Ver1_1 file.
2. The materials are pre-configured, but please adjust them as needed for your project.
3. For instructions on using EasyRoads3D, please watch the video linked below. 
"UnityRoadMaster How to Set UP（https://youtu.be/EtXFhnFdS3M）"
"UnityRoadMaster Extra Data(https://youtu.be/qNTTEt0UuT8)



## System Requirements
- Unity 2021.3.18f
- EasyRoads3D v3.2.4f2
