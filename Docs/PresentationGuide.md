# Pedalty 発表準備ガイド（チーム全員用）

ブース審査・デモ審査で、全員がハードウェアとソフトウェアの両方を説明できるようにするための資料です。
コードと設定ファイルから確認した事実だけを書いています。**「★要確認」の箇所はコードからは分からないので、担当者が埋めてください。**

---

## 1. まず覚える「30秒説明」

> Pedalty は、**本物の自転車をこいで操作する**交通ルール学習ゲームです。
> 車輪の回転・ハンドルの角度・手元のボタンをセンサーで読み取り、Unity で作った街の中を走ります。
> 信号無視や逆走などの違反をすると、**その場で違反名・法律上の説明・罰金額**が表示されます。
> ゴールまでの**タイムと罰金額**を競うことで、楽しみながら自転車の交通ルールを体で覚えられます。

覚え方：**「本物の自転車」→「センサーで読む」→「違反をその場で教える」→「タイムと罰金で競う」**

---

## 2. 全体の仕組み（1枚の図）

```
[自転車]                    [Arduino]                 [PC / Unity]
 車輪の磁石 ──→ マグネットセンサ(D2) ─┐
 ハンドル   ──→ ポテンショメータ(A0) ─┼→ USBシリアル通信 ─→ 受信 → 速度・角度・ボタンに変換
 右ボタン   ──→ D3 ──────────────────┤   (115200bps)        → 自転車を動かす
 左ボタン   ──→ D4 ──────────────────┘                      → 違反を判定 → 画面に表示
```

データの流れは **センサー → Arduino → USB → Unity → 画面** の一方通行です（Unity から Arduino へは何も送っていません）。

## 3. ハードウェア

### 3.1 センサーと役割

| 部品 | つなぐピン | 何を測るか | ゲームでの役割 |
|---|---|---|---|
| マグネットセンサ ★種類要確認（リードスイッチ／ホールセンサ） | D2 | 車輪が1回転した瞬間 | こぐ速さ → 自転車の速度 |
| ポテンショメータ（可変抵抗） | A0 | ハンドルの角度（0〜1023の数値） | 左右に曲がる |
| 右ボタン | D3 | 押している／離している | ベルを鳴らす・メニューの「次へ」 |
| 左ボタン | D4 | 押している／離している | ブレーキ・メニューの「戻る」 |

- ★要確認：Arduino の機種（Uno など）、自転車の固定方法（ローラー台・スタンドなど）、磁石の取り付け位置。
- 設定上、磁石は車輪に **1個**（`magnetsPerWheel: 1`）、車輪の周長は **2.096m**（`wheelCircumference`）です。
- 実物のブレーキレバーはゲームに連動していません。ブレーキは左ボタンです。

### 3.2 Arduino のプログラムがやっていること

ファイル：`arduino_program/ard_simple-button.cpp/`

| 工夫 | 内容 | なぜ必要か |
|---|---|---|
| 内蔵プルアップ | ボタンとセンサーは「ピン ↔ GND」につなぐだけ。離している時 HIGH、押すと LOW | 外付けの抵抗が要らず、配線が簡単になる |
| 割り込み | 磁石の検出（D2）は、信号が落ちた瞬間（FALLING）に割り込みで処理 | 一瞬の信号を取りこぼさないため |
| チャタリング対策（磁石） | 前回の検出から 200ms 以内の信号は無視 | 1回の通過で何回も反応するのを防ぐ |
| デバウンス（ボタン） | 値が 100ms 変わらなかった時だけ「押した／離した」と確定 | 接点のばたつきによる誤入力を防ぐ |
| オーバーサンプリング | ハンドルの値は 8回読んで平均 | ノイズで値がふらつくのを抑える |
| 停止の通知 | 2秒間磁石が来なければ「止まった」と送る | こぐのをやめたら自転車を止めるため |

### 3.3 Arduino → PC に送るデータ

USB のシリアル通信（**115200bps**）で、1行ずつ文字で送ります。

| 送る内容 | 形式（例） | 送る間隔 |
|---|---|---|
| ハンドルの値 | `POT,512` | 20ms ごと（1秒に50回） |
| ボタンの状態 | `1,0`（右,左。押=1／離=0） | 50ms ごと（1秒に20回） |
| 車輪1回転にかかった時間 | `MAGNET,850`（ミリ秒） | 磁石を検出するたび |
| 停止 | `MAGNET,0` | 2秒間検出がない時 |

## 4. ソフトウェア（Unity）

開発環境：Unity（URP）／言語は C#。自作スクリプトは `Assets/Scripts/` にあります。

### 4.1 入力の処理

**(1) 受信**（`ArduinoConnection.cs`）
- ゲームの処理を止めないよう、**別スレッド**でシリアルポートを読み続けます。
- ポートは `AUTO` 設定で自動検出します。Arduino がなくても**キーボードで遊べます**（開発・デバッグ用）。

**(2) 速度の計算**（`WheelSpeedConverter.cs`）

```
実際の速度[km/h] = 車輪の周長[m] ÷ 1回転の時間[秒] × 3.6
```

例：1回転に 0.85秒 → 2.096 ÷ 0.85 × 3.6 ≒ **8.9 km/h**

- ゲーム内の速度は、実際の速度の **2倍**（`speedMultiplier`）にしています。室内でこぐ速さでも爽快に走れるようにするためです。上限は 40km/h。
- 磁石は1回転に1回しか反応しないので、そのままだと速度がカクカクします。そこで**なめらかに近づける処理**（平滑化）を入れています。
- 2.5秒間パルスがなければ、速度を0にします。

**(3) ハンドルの処理**（`HandleAngleConverter.cs`）

| 処理 | 内容 | 目的 |
|---|---|---|
| 正規化 | 0〜1023 の値を、中央を0として −1〜+1 に変換 | 左右を同じ扱いにする |
| 不感帯（5%） | 中央付近の小さな動きは 0 にする | 手を離した時のふらつきを消す |
| カーブ補正 | 中央付近は鈍く、大きく切ると強く効く | まっすぐ走りやすくする |
| 感度（0.6倍） | 曲がる量を抑える | 試走で「曲がりすぎる」と分かったため |
| 平滑化 | 値を少し遅れて追いかける | センサーのノイズを消す |

- 中央・左端・右端の値は、**キャリブレーション**（較正）して `settings.json` に保存します。自転車を組み直しても、ソフトを作り直さずに調整できます。

### 4.2 違反の判定（このゲームの中心）

**(1) 今どこを走っているかの判定**（`PlayerLaneDetector.cs`）
- 道路には、車道・自転車道・歩道ごとに**見えない判定の箱**が置いてあります。自転車に一番近い箱で「今どのレーンにいるか」を判定します。
- 道路の中央線を基準に、進行方向の**左側か右側か**も判定します（右側なら逆走）。
- 交差点で信号待ちのために横を向いても逆走にならないよう、**135°以上向きを変えた時だけ**逆向きと判定します。

**(2) 違反の種類**（内容と金額は `Assets/Resources/Violations/violations.json`）

| 違反 | どんな時 | 罰金 |
|---|---|---|
| 車道通行義務違反 | 歩道を走った | 6,000円 |
| 専用通行帯通行義務違反 | 自転車道があるのに車道を走った | 5,000円 |
| 右側通行（逆走） | 車道・自転車道の右側を走った | 6,000円 |
| 信号無視 | 赤信号で横断歩道まで進んだ | 6,000円 |
| 信号無視（自転車歩行者専用信号） | 「歩行者・自転車専用」の交差点で、歩行者信号が赤なのに渡った | 6,000円 |
| 自転車横断帯通行義務違反 | 自転車横断帯を通らずに交差点を渡った | 5,000円 |
| 警音器使用制限違反 | 周りに誰もいないのにベルを鳴らした | 3,000円 |
| 歩行者との衝突 | 歩行者にぶつかった | 6,000円 |

- 「一時不停止」（5,000円）はデータには入っていますが、**判定はまだ実装していません**。聞かれたら「今後の課題」と答えてください。
- ★要確認：罰金額の根拠（2026年4月開始の自転車の青切符の反則金額を参考にしたか）。

**(3) 理不尽にならないための工夫**
- **猶予**：違反のレーンに **1秒** いたら違反。少しはみ出しただけでは違反になりません。
- **例外**：路上駐車の横では歩道や車道に出てよい／「自転車及び歩行者専用」の歩道は走ってよい／自転車道がない道路は車道の左側を走ってよい。
- **二段階右折**にも対応。交差点で向きを変えて2回目の横断を始めた時に、その方向の信号を判定します。

**(4) 違反した後**（`BicycleRecovery.cs`）
- 違反していない時の位置を **0.2秒ごと**に記録しています（最大150個＝約30秒分）。
- 違反・衝突の時は**暗転して、違反する前の位置へ戻し**、向きもそのレーンの正しい進行方向に直します。
- その後、違反の内容と罰金額のポップアップが上から落ちてきます。

### 4.3 街の中の車と歩行者
- **車**：外側の道路から出現し、交差点でランダムに直進・右折・左折。信号、対向車、横断中の歩行者・自転車を待ちます。曲がる時は速度を7割に落とし、ウインカーを出します。
- **歩行者**：歩道を歩き、信号に従って横断。自転車が近づくと立ち止まるか、横によけます。
- **信号**：交互式と歩車分離式（スクランブル）の2種類。「歩行者・自転車専用」信号の交差点もあります。

### 4.4 ゲームの流れ
スタート画面 → ルール説明（5ページ）→ カウントダウン → 走行 → ゴール → 結果（タイム・罰金）→ ランキング

- ランキングは **タイム順**で、記録は PC 内の JSON ファイルに保存します。
- 設定（通信ポート、車輪の周長、速度の倍率、ハンドルの較正値など）は `settings.json` で変更でき、**ゲームを作り直さずに現場で調整**できます。

## 5. 想定質問と答え方

### コンセプト
**Q. なぜ作ったのですか？**
★チームで決めた動機を入れてください。例：「2026年4月から自転車にも青切符（反則金）が導入され、ルールを知らないと罰金を取られる時代になった。でも学ぶ機会は少ないので、体を動かして楽しく覚えられるものを作った」

**Q. 既存の自転車シミュレーターとの違いは？**
違反を「その場で」「法律上の名前と罰金額つきで」教える点と、タイムと罰金を競うゲームにした点です。

**Q. 誰に使ってほしいですか？**
★例：自転車通学の中高生、交通安全教室、免許を持たない人。

### ハードウェア
**Q. 速度はどうやって測っていますか？**
車輪に付けた磁石がセンサーの前を通る間隔を測っています。「周長 ÷ 1回転の時間」で速度になります。

**Q. なぜ磁石は1個なのですか？**
構造が単純で取り付けやすいからです。そのぶん速度の更新が粗くなるので、ソフト側でなめらかにしています。磁石を増やせば精度は上がります（設定で個数を変えられます）。

**Q. ハンドルの角度はどう測っていますか？**
ハンドルの回転軸にポテンショメータ（回すと抵抗値が変わる部品）を付け、Arduino が電圧として 0〜1023 の数値で読んでいます。

**Q. 誤動作への対策は？**
磁石は 200ms 以内の連続信号を無視、ボタンは 100ms 安定してから確定、ハンドルは 8回の平均。さらに Unity 側で、押しっぱなしで信号が張り付いたボタンを無視する仕組みもあります。

**Q. Arduino と PC はどう通信していますか？**
USB のシリアル通信（115200bps）です。`POT,512` のように「種類,値」の文字を1行ずつ送る単純な形式なので、デバッグしやすくなっています。

### ソフトウェア
**Q. 違反はどうやって判定していますか？**
道路に車道・自転車道・歩道ごとの見えない箱を置き、自転車がどの箱にいるか、中央線のどちら側かを毎フレーム調べています。信号は、交差点の手前の横断歩道の範囲に入った瞬間の色で判定します。

**Q. 少しはみ出しただけで違反になりませんか？**
1秒の猶予があります。また、路上駐車をよける時や、歩道を通ってよい標識のある場所は違反になりません。

**Q. 違反したらどうなりますか？**
暗転して違反する前の位置に戻り、違反名・説明・罰金額が表示されます。0.2秒ごとに安全な位置を記録しているので、その場所へ戻せます。

**Q. 一番難しかったところは？**
★自分の担当で答えてください。ソフトの例：「実際に試走すると、交差点で信号待ちのために横を向いただけで逆走になる、止まっているだけで違反になる、などの誤判定がたくさん出た。原因を1つずつ突き止めて、角度に余裕を持たせる・猶予を付けるなどして直した」

**Q. 交通ルールは正確ですか？**
道路交通法をもとにしています（歩道通行の原則禁止、左側通行、自転車横断帯、歩行者・自転車専用信号、二段階右折など）。ただしゲームとして簡略化している部分もあります。

### 弱点を聞かれた時
**Q. 課題や今後の予定は？**
- 一時停止の判定が未実装。
- 速度は磁石1個なので、低速時の反応が少し遅い。
- 実物のブレーキレバーとは連動していない（ボタンで代用）。
- ★ほかにチームで感じている課題。

答え方のコツ：**課題は隠さず、「原因」と「次にどうするか」をセットで話す**と評価されます。

- 「担当に確認します」と言って、分かる人につなぐ。

- 数字を聞かれたら、この資料の太字（115200bps、2.096m、1秒、0.2秒、135° など）を使う。
